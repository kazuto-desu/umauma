# うまうま展開予想

出走馬の過去の通過順と今回の枠順から、**1コーナー**と**最終コーナー**の隊列を予想して図で表示する個人用アプリ。

## できること

- 競馬サイトの出馬表・馬柱をコピペすると、馬番・馬名・過去の通過順を取り出す (無料・APIキー不要)
  - スクショしかない場合は iPhone のテキスト認識表示で文字をコピーして貼り付ける
  - 表に馬名が入っていれば、その馬名を目印に通過順だけを更新する
- 通過順の手入力・修正 (`3-3-2-1/16 5-4/14` のように1走ずつ空白区切り、`/` の後ろは頭数)
- 脚質 (逃げ/先行/差し/追込) と想定ペースの判定
- コースの特徴を反映 (JRA 10場の主要コース。1コーナーまでの距離・直線の長さ・芝スタートのダートなど)
- 過去走の距離・芝ダートの違いを補正 (貼り付けたテキストに「芝1800」などがあれば拾う)
- 各馬に展開が向くかどうか (有利/不利) を表示
- 取消・除外の馬をチェックで隊列から外せる
- 1コーナー・最終コーナーの隊列図 (枠色の丸に馬番)。PNG で保存できる
- 通過順表記 (例: `(1,3,8)-6,12(4,10)`) の表示
- 入力したレースはブラウザに自動保存

## 使い方

```bash
npm install
npm run dev     # http://localhost:5173
npm test
npm run build
```

## 予想ロジック (src/lib/predict.ts)

1. 近走ほど重みを付けて、各走の最初のコーナー位置・最後のコーナー位置を頭数で 0〜1 に正規化して平均
   - 今回より短い距離の過去走は前寄りに、長い距離は後ろ寄りに補正 (延長は前に行きやすい)
   - 芝とダートが違う過去走は参考度を下げる
2. 1コーナー: 枠順で補正。強さはコースで変わる (最初のコーナーが近いほど外枠不利、芝スタートのダートや直線コースは外枠が有利)
3. 前に行きたい馬の数からペースを判定し、ハイなら前が苦しく、スローなら前残り。直線が長いほど差しが届きやすい
4. 位置を馬身に換算し、内外のレーンを割り当てる (1コーナーは枠なり、最終コーナーは押し上げる馬ほど外)

コースの数値は src/lib/courses.ts の表にある (概算の目安)。間違いを見つけたらここを直す。
