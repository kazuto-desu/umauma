# うまうま展開予想

出走馬の過去の通過順と今回の枠順から、**1コーナー**と**最終コーナー**の隊列を予想して図で表示する個人用アプリ。

## できること

- 馬柱のスクリーンショットを読み込むと、Claude が枠・馬番・馬名・過去の通過順を読み取る
- 通過順の手入力・修正 (`3-3-2-1/16 5-4/14` のように1走ずつ空白区切り、`/` の後ろは頭数)
- 脚質 (逃げ/先行/差し/追込) と想定ペースの判定
- 1コーナー・最終コーナーの隊列図 (枠色の丸に馬番)。PNG で保存できる
- 通過順表記 (例: `(1,3,8)-6,12(4,10)`) の表示
- 入力したレースはブラウザに自動保存

## 使い方

```bash
npm install
npm run dev     # http://localhost:5173
npm test
npm run build
```

画像の読み取りには Anthropic の APIキーが必要。キーはブラウザの localStorage にだけ保存され、ブラウザから直接 API を呼ぶ (自分専用で使う前提)。

## 予想ロジック (src/lib/predict.ts)

1. 近走ほど重みを付けて、各走の最初のコーナー位置・最後のコーナー位置を頭数で 0〜1 に正規化して平均
2. 1コーナー: 外枠ほど少し後ろに補正 (「枠順の影響」で調整)
3. 前に行きたい馬の数からペースを判定し、ハイなら前が苦しく、スローなら前残りに補正
4. 位置を馬身に換算し、内外のレーンを割り当てる (1コーナーは枠なり、最終コーナーは押し上げる馬ほど外)

## 公開
